# Self-hosted fonts

Generated by `tools/fetch_fonts.py`. Latin subsets only.

- **Manrope** — variable weight 400–700, one file per subset.
- **DM Mono** — static 400 and 500.

Both are licensed under the SIL Open Font License 1.1; the copyright
notices are in `OFL-Manrope.txt` and `OFL-DM-Mono.txt`, which must stay
alongside the font files when the site is deployed.
